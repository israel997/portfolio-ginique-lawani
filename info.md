# Fiche projet pour le portfolio

> **À qui s'adresse ce document** : à l'assistant IA (ou à la personne) qui travaille dans ce dépôt.
> **Ce qu'il faut faire** : analyser ce projet et remplir la fiche ci-dessous. Elle sera recopiée telle quelle dans le portfolio de Ginique LAWANI (Admin → Projets).

## Règles

- **Se baser sur le code réel** : `README`, `package.json` (ou équivalent), structure des dossiers, configuration, historique Git. Ne rien inventer. Si une information est introuvable, écrire `À compléter`.
- **Ce que Ginique a fait** : s'appuyer sur ses commits (`git log --author="Ginique" --author="israel997" --author="LAWANI"`). S'il n'est pas le seul contributeur, ne lister que ses contributions.
- **Court, direct, sans jargon inutile.** Écrire en français ; les noms de technologies restent tels quels.
- **Pas de tiret cadratin (—)** ; utiliser des virgules ou des deux-points.
- Respecter les longueurs indiquées : le site coupe les textes trop longs.

## Fiche à rendre

Rendre uniquement le bloc ci-dessous, rempli :

```markdown

- <technologie>

<2 à 3 phrases maximum. Le contexte, le problème résolu, la solution.>
```
